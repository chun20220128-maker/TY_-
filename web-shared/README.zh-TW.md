# 鑽探工作台：公司共用帳密網頁版

本版由管理者設定一組公司共用帳號、密碼。工程師開啟網站登入即可，不需要註冊。單機版不變。

## 更新現有 Cloudflare Pages 網站

1. Cloudflare → Workers & Pages → 原有鑽探工作台專案 → Settings → Variables and Secrets，選 Production／正式環境。
2. 新增兩筆 **Secret／機密**：
   - 名稱 `LOGIN_USERNAME`，值填您自訂的公司共用帳號。
   - 名稱 `LOGIN_PASSWORD`，值填您自訂的密碼，至少 12 個字元，請勿在對話、截圖或公開儲存庫揭露。
3. 原有 D1 繫結 **`DB` → `drilling-history`** 保持原樣。不要刪除、重建資料庫，原本 14 案／322 筆會繼續使用。
4. 到 Deployments → Create deployment → Production，上傳 `DrillingWorkbench_Company_Web_Login.zip`，部署成功後設定才會套用。
5. 直接開啟原本固定的 `https://您的專案.pages.dev/`，輸入共用帳密登入。舊的 `#access=...` 專用連結不再提供登入權限。
6. 開無痕視窗確認未登入時只有登入畫面；登入後確認歷史單價仍為 14 案／322 筆，再分享給同仁。

不需要新增 `SESSION_SECRET` 或重做資料匯入。舊的 `ACCESS_TOKEN_SHA256` 本版不使用，可以從正式環境設定刪除；舊專用連結產生頁 `/setup` 已停用。

## 帳密管理

- 更換公司密碼：修改 `LOGIN_PASSWORD` 機密，再部署同一份 ZIP。新版部署生效後，舊登入狀態即無效，必須重新登入。
- Cookie 為 Secure、HttpOnly、SameSite=Strict，8 小時到期。右側工作內容仍由工程師自行匯出備份；登入不會自動儲存專案。
- 工作台左側新增「登出」，未備份的專案會提示確認。登出會撤銷本次工作階段。
- 同一來源 IP 在 15 分鐘內最多 10 次登入嘗試，成功登入會清除計數。公司共用對外 IP 時，連續輸錯可能影響其他同仁，請等 15 分鐘再試。
- 共用帳密可能被轉傳，不提供個別員工身分識別，也無法只撤銷某一員工的權限。
- 可查看資料的人仍能複製或截圖，沒有提供防拷貝保證。

## 資料與功能

- 歷史契約單價全公司共用於 D1。工程師網頁介面及 API 不提供歷史單價匯入／匯出。
- 專案只留在本次畫面記憶體；關閉前請自行匯出備份。專案備份不包含整份歷史單價資料庫。
- 公開部署 ZIP 沒有真實單價、公司帳密或原 Word/Excel 的已填寫資料。
- D1 新增 `web_sessions` 及 `web_login_limits` 兩個登入管理資料表，不改寫原有歷史單價資料表。
- 密碼與會話 token 不寫入瀏覽器 localStorage。D1 僅存會話 token 的 SHA-256，不存明文 token、帳號或密碼。

## 已驗證範圍

本機 D1 相容測試與實際 Chromium 測試：登入成功／失敗、舊連結與未登入 API 拒絕、私有資產拒絕、跨來源拒絕、登入次數限制、工作階段失效與密碼變更、登出撤銷；兩位工程師獨立專案、歷史資料查閱、專案備份還原、刷新空白專案、Word 需求表與 Excel 估價輸出。

尚未代為部署到您的 Cloudflare 帳號；正式部署後仍需依第 6 步驗收。工程師不必下載管理者使用的部署 ZIP。
