鑽探工作台 1.0.5 完整離線安裝版（Windows 10／11 x64）

取得 Setup.exe 後即可離線安裝，不需要網路、帳號、Python、Chrome 或 Edge。安裝元件已全部內含。安裝於目前使用者可寫入的資料夾，預設 %LOCALAPPDATA%\Programs\DrillingWorkbench。

專案作業
每次完整啟動都是空白新專案。只有按「匯出備份」才會將規劃、估價、契約與請款資料保存成 JSON 檔；按「匯入備份」可以接續作業。
操作中的專案只暫存在執行中的記憶體，不自動寫入專案檔案。完整結束、電腦重新啟動或程式異常停止後，未匯出的作業不保留。
按視窗 × 只關閉視窗，程式仍在背景執行。右下角執行中圖示可雙擊開啟原作業；Windows 可能把圖示收在隱藏的圖示區。
按左側或圖示右鍵的「結束程式」，可以選先備份再結束、不備份結束，或取消。取消／備份失敗會保持開啟。完成結束後圖示消失。

歷史契約單價
內建 14 案／322 筆歷史單價。後續匯入的歷史 CSV 自動儲存於安裝資料夾 data/history.sqlite3，跨新專案及重新啟動持續保留。
data/history-backup.sqlite3 是資料庫備份。data/history-pending.json 僅暫存尚未寫入的歷史紀錄，不含專案作業。
data/browser-profile 為此程式獨立的視窗設定；exports 為預設匯出位置，可另選保存位置。
資料在本機磁碟，不使用雲端。沒有應用程式帳號、網域綁定或按使用者授權的限制；不同 Windows 使用者各自安裝並使用各自的資料。

升級與移除
更新前先匯出正在作業的專案、按「結束程式」，再執行新安裝檔。升級保留既有歷史資料庫、舊版存檔與使用者匯出檔案，不自動讀回舊專案。
解除安裝保留 data 與 exports。請定期備份歷史資料庫資料夾與自行匯出的專案 JSON 到其他磁碟。
本程式未附數位簽章；公司電腦的安裝與防毒政策仍由各單位管理。

本機網頁入口
雙擊「鑽探工作台-網頁入口.exe」使用電腦原有 Chrome／Edge，仍連線至自己的 127.0.0.1，沿用本機 SQLite。也可單獨下載 DrillingWorkbench_Web_Start.exe，直接用於已安裝的 1.0.4，不需重裝。請先關閉原先的錯誤視窗。
